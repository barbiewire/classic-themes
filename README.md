## FASTEST WAY (windows):
open powershell and paste this:

```powershell
irm https://raw.githubusercontent.com/barbiewire/classic-themes/main/install.ps1 | iex
```

it downloads everything, dumps it in %LOCALAPPDATA%\ClassicThemes, copies that path to your
clipboard and opens the folder
then just do steps 2 and 3 below and drag the folder in

run it whenever there's an update
THEN press the reload button in your broswer://extensions

dont wanna trust random scripts?

--load-extension now (tested on chrome 152 and brave 153) and the only true one click
install is the $5 web store, so FUCK no

## OR DO IT MANUALLY:

Since I'm NOT PAYING $5 TO PUBLISH A CHROME EXTENSION, do this:

1. Go to your browser's extension manager (if you can't do this idk what to tell you)
> prob this if you're on chrome:
> chrome://extensions/
> or if you're on brave like me:
> brave://extensions/

2. If you see the developer mode toggle PRESS IT
> just press the one on the top right

3. Press load unpacked
> It's on the top left

4. Load the extracted folder
> Extract the zip then use that folder
> pick the folder that has manifest.json DIRECTLY inside it not the one above it
> if it says "manifest file is missing" you picked the wrong folder dumbass

5. DON'T delete or move the folder after
> chrome loads it from there every time
> delete it and the extension gets massacred
